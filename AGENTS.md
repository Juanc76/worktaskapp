# Trabajo en worktaskapp

Worktask es independiente. La base documental se encuentra fuera de los repositorios de código.

Antes de trabajar, resolver WORKTASK_DOCS_ROOT o consultar .worktask-docs.yml. Leer 00_INICIO/WORKTASK.md, CONTEXTO_ACTUAL.md y 10_GOBIERNO/PROTOCOLO_AGENTES.md; consultar luego el módulo pertinente.

Respetar instrucciones del usuario y cambios ajenos. Documentar archivos afectados, estado Git, pruebas ejecutadas, limitaciones y relevo. No guardar secretos ni afirmar verificaciones no realizadas.

Si la base no está disponible, informar la limitación y continuar el trabajo autorizado, dejando pendiente el relevo documental.
